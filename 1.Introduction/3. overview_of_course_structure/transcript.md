# Overview of course structure

## Summary

This introductory video outlines the structure and teaching philosophy of the upcoming database course, emphasizing conceptual understanding over rote memorization.

### Key Takeaways

- **Teaching Philosophy:** Students are encouraged to focus on understanding theoretical frameworks and mental models rather than memorizing syntax. The instructor advises using documentation or AI tools for specific references.
- **Data & Environment:**
  - All course data is available for download.
  - Users can run the database locally using Docker or postgres.app (for Mac users).
  - Alternatively, students can use cloud-hosted options like Supabase or the built-in browser-based SQL editor provided on the course platform, which connects to a real Postgres database.
- **Tools:** The instructor recommends visual database clients such as TablePlus (personal favorite), DBeaver, Postico, or Datagrip. The course demonstrations will utilize the Supabase web UI.
- **Support:** The instructor offers direct support via email for any students who get stuck or have questions.
